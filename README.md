# Mercado Livre Clone

Projeto demonstrativo de interface inspirado em um marketplace, construído com HTML, CSS e JavaScript puro.

## Estrutura

```text
/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Como executar

Abra o arquivo `index.html` diretamente no navegador ou publique a raiz do repositório com GitHub Pages.

## Funcionalidades

- Header com busca, localização e carrinho
- Barra de categorias
- Banner promocional
- Grade de produtos gerada via JavaScript
- Contador simples de carrinho
- Filtro visual por categoria
- Layout responsivo baseado em CSS Grid

## Observação

Este projeto é apenas uma demonstração de UI e não possui vínculo oficial com o Mercado Livre.
